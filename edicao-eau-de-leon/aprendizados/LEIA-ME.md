# Aprendizados (base de conhecimento local)

Aqui a skill guarda, em `aprendizados.md`, cada alteração que o usuário pediu, para não repetir o mesmo erro nas próximas edições. O arquivo é criado sozinho na primeira lição (`scripts/aprender.py`).

- É **desta máquina**: não vem do GitHub e os instaladores o preservam ao atualizar a skill.
- Vale mais que o `treinamento/`: é o pedido mais recente de quem usa a skill.
- Como funciona: `treinamento/12-aprendizados.md`.
- Para mandar ao dono da skill: `python scripts/aprender.py exportar`.
